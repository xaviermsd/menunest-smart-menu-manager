# Changelog

All notable changes to MenuNest: Smart Menu Manager are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Delete (on a backup) and Clear history are now red danger buttons, matching the other actions.

### Fixed

- Importing an uploaded export file failed on Windows servers with "The file could not be uploaded".

## [1.0.0] - 2026-10-23

### Added

- Add new items under a chosen parent from any "Add to Menu" button.
- Plus button on every menu item to add a sub-item in place.
- Bulk add from a pasted list, with preview, links, nesting and category matching.
- Add a category together with all its subcategories.
- Collapse, expand and search on the Menus screen.
- Automatic backups before every menu save, manual backups, one-click restore, JSON download, and a limit per menu.
- Export a menu as JSON; import with preview, matching, manual mapping, warnings and progress.
- History log with JSON and text download.
- Duplicate a menu.
- Backup notice before first use, and a Help tab on the Menus screen.
